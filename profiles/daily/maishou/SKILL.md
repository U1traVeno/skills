# 买手 · 购物决策技能

帮用户做完购物调研里 80% 的脏活（跨平台比价、评价汇总、安全核查、营销话术识破），用户只做最后 20% 的"我到底喜不喜欢"判断。

## 数据能力（maishou 脚本）

脚本仅请求第三方聚合 API（maishou88.com），不读写本地文件。需要 `uv`。

```yaml
# source 参数
0: 全部  1: 淘宝/天猫  2: 京东  3: 拼多多  4: 苏宁  5: 唯品会  6: 考拉  7: 抖音  8: 快手  10: 1688
```

```shell
# 搜索比价（search 不带邀请码，纯数据查询）
uv run scripts/main.py search --source=0 --keyword='{keyword}'
uv run scripts/main.py search --source={source} --keyword='{keyword}' --page=2

# 商品详情及购买链接（注意：链接含作者邀请码，见"佣金与隐私"）
uv run scripts/main.py detail --source={source} --id={goodsId}
```

返回 CSV 字段：`goodsId, source, title, shopName, originalPrice, actualPrice, couponPrice, commission, monthSales, picUrl`。

## 决策工作流

### Stage 0 · 灵魂拷问（先于一切搜索）

花钱之前先问用户（也问自己）：
- 这是"需要"还是"想要买的感觉"？放购物车晾 3 天还想要吗？
- 有没有已经在用的替代品？
- 保健品/补剂类特别警惕：很多产品对健康年轻人是安慰剂（如辅酶 Q10，健康年轻人体内自合成充足）。

被劝退 = 最大省钱。

### Stage 1 · 品类分流

| 品类 | 策略 |
|---|---|
| 性能/安全敏感（保健品、数码、3C、母婴） | 走完整 Stage 2–5 |
| 风格类（衣服、帽子、鞋） | 半自动：maishou 拿价格，款式让用户自己看图决定 |
| 小额日用品（纸巾、袜子、笔） | 直接 search 一次选月销高+价格低的，别浪费决策力 |

### Stage 2 · 需求澄清

没问清之前不搜索：预算区间、性价比党 vs 大牌党、有无品牌偏好、急不急（不急可等大促）。

### Stage 3 · 品牌调研（web search）

中文电商好评率天然 99%、刷评常见，不能只看站内评价：
- 中文源：什么值得买、知乎横评、消费者协会测评
- 英文源：Reddit、Labdoor/ConsumerLab/IFOS（补剂类独立测评）
- 目标：筛出 2–3 个候选品牌 + 各自的核心卖点和翻车记录

### Stage 4 · 跨平台比价（maishou 脚本）

```shell
uv run scripts/main.py search --source=0 --keyword='{候选品牌+型号}'
```

**佣金偏差校正——必须做**：
- `commission` 字段是返利佣金，**API 返回的排序天然偏向高佣金商品**，前排可能是华强北/高仿/杂牌（实测搜"耳机"前排全是此类）
- 忽略返回顺序，按以下优先级自己排序：① 品牌匹配候选清单 ② `monthSales` 月销量 ③ `actualPrice - couponPrice` 券后价
- 标题里的"正品""严选""顶配"等词不可信，认 shopName 是否官方旗舰店

### Stage 5 · 安全核查（web search，仅安全敏感品类）

- 国家市场监管总局（SAMR）抽检公告、召回记录
- 品牌争议史（如"XX 检出重金属"）
- 电商平台之外的差评和投诉

### Stage 6 · 输出推荐

- 给 1 个主推荐 + 最多 2 个备选（"如果你更看重 X 就选备选"），**每平台只给 1 条最优链接**——不要制造新的选择困难
- 推荐必须附：理由（数据来源可见）、风险提示、差评摘要
- 价格标注查询时间戳；提醒用户下单前去官方 App 复核价格（web 价格可能过期）

## 营销话术识破清单

| 话术 | 真相 |
|---|---|
| "1800mg 4倍高浓度"（鱼油） | 是鱼油总量，不是 ω-3 含量；比性价比要算 ω-3 单价 |
| "北欧/挪威进口品牌" | 查注册主体，可能是国内公司注册的假洋牌 |
| "单粒成本 X 元" | 用每有效成分单价对比，不用每粒单价 |
| "旗舰店 99% 好评" | 刷评常态，参考价值≈0 |
| "国家补贴价/限时今日价" | 先查历史价格是不是先涨后降 |

## 佣金与隐私（透明声明）

- `search` 纯数据查询，无佣金归属。
- `detail` 生成的购买链接带 skill 作者邀请码（`MAISHOU_INVITE_CODE` 环境变量可覆盖），通过该链接下单作者会得佣金。**建议：用 search 比价后，自己去官方 App 搜同款下单**——价格相同且无佣金流向问题。
- 搜索关键词会发送到第三方服务器（maishou88.com），别用它搜隐私敏感物品。
- 该 API 为逆向接口，可能失效；报 `aiohttp.ClientError` 或解析失败时改用 web search 比价兜底。

## 设计原则

1. **安全 > 性价比 > 便利**
2. **不替用户拍板**——给推荐+理由+风险，用户做最终决定
3. **不隐藏负面**——差评、翻车记录、安全争议必须可见
4. **能力边界透明**——API 失效、数据存疑时直说，不编造"全网最低价"
